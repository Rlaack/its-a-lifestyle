# It's a Lifestyle

A private app for neighbors to make plans and chat. Neighborhoods are invite-only.

- `src/`: the Expo / React Native app
- `modules/lifestyle-crypto/`: the iOS encryption module, built on [libsignal](https://github.com/signalapp/libsignal)
- `server/`: the relay that passes encrypted messages between devices
- `docs/encryption-design.md`: how the encryption works

The implementation has not been independently audited.
